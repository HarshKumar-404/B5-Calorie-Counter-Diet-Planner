# B5 – Calorie Counter & Diet Planner

A Flutter-based calorie counter and diet planner designed to help users track food intake, monitor calories, plan vegetarian meals, and follow their nutrition progress.

## Features

- **Calorie Tracking** – Track daily calorie intake.
- **Food Logging** – Record meals and food items.
- **Diet Planning** – Plan daily meals with vegetarian food options.
- **Progress Tracking** – Monitor nutrition and progress over time.
- **Water Tracking** – Keep track of daily water intake.
- **Flutter UI** – Cross-platform interface built with Flutter and Material Design.

## Tech Stack

- **Frontend:** Flutter, Dart
- **UI Framework:** Material Design 3
- **Local Storage:** SharedPreferences
- **Hosting / Backend Services:** Firebase (as configured)

## Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or Visual Studio Code
- An emulator or physical device

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/motivxcel404-dev/B5-Calorie-Counter-Diet-Planner.git
   ```

2. Open the project directory:

   ```bash
   cd B5-Calorie-Counter-Diet-Planner
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```

## Run on Web

```bash
flutter build web
```

The generated web files will be available in `build/web`.
