# B5 – NeutriFIT: Calorie Counter & Diet Planner

NeutriFIT is a Flutter-based calorie counter and diet planner designed to help users track daily calorie intake, log meals, plan vegetarian diets, monitor water consumption, and track nutrition progress.

## 🔗 Important Links

- **🌐 Live App:** [Open NeutriFIT](https://neutrifit-e4cec.web.app/)
- **📦 GitHub Repository:** [B5 – Calorie Counter & Diet Planner](https://github.com/HarshKumar-404/FLUTTER-PROJECT-B5---Calorie-Counter-Diet-Planner)
- **🔥 Firebase Project Console:** [Open Firebase Console](https://console.firebase.google.com/project/neutrifit-e4cec/overview)

## ✨ Features

- **Calorie Tracking** – Track daily calorie intake.
- **Food Logging** – Record food items and daily meals.
- **Diet Planning** – Plan meals with vegetarian food options.
- **Progress Tracking** – Monitor nutrition and progress over time.
- **Water Tracking** – Keep track of daily water intake.
- **Modern UI** – User interface built with Flutter and Material Design 3.
- **Cross-Platform Project** – Flutter project structure for Android, iOS, web, and desktop, subject to platform configuration and testing.

## 🛠️ Tech Stack

- **Frontend:** Flutter and Dart
- **UI Framework:** Material Design 3
- **Local Storage:** SharedPreferences
- **Web Hosting:** Firebase Hosting
- **Version Control:** Git and GitHub

## 🚀 Getting Started

### Prerequisites

Install the following tools to run the project locally:

- [Flutter SDK](https://docs.flutter.dev/get-started/install)
- [Dart SDK](https://dart.dev/get-dart)
- [Android Studio](https://developer.android.com/studio) or [Visual Studio Code](https://code.visualstudio.com/)
- An Android emulator, a compatible physical device, or a configured web browser

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/HarshKumar-404/FLUTTER-PROJECT-B5---Calorie-Counter-Diet-Planner.git
```

**2. Navigate to the project directory**

```bash
cd FLUTTER-PROJECT-B5---Calorie-Counter-Diet-Planner
```

**3. Install dependencies**

```bash
flutter pub get
```

**4. Run the application**

```bash
flutter run
```

To run the application in Chrome:

```bash
flutter run -d chrome
```

## 🌐 Run the Web Application Locally

Build the Flutter web application using:

```bash
flutter build web
```

The generated web files will be available in the `build/web` directory.

To test the production build locally, serve the contents of `build/web` using a local HTTP server.

## 🔥 Firebase Hosting Deployment

The project uses Firebase Hosting for its deployed web application.

### Prerequisites

- Install the [Firebase CLI](https://firebase.google.com/docs/cli).
- Sign in using a Google account that has access to the Firebase project.
- Ensure the Firebase project and Hosting configuration are correct.

### Deployment Steps

**1. Sign in to Firebase**

```bash
firebase login
```

**2. Select the Firebase project**

```bash
firebase use neutrifit-e4cec
```

**3. Build the Flutter web application**

```bash
flutter build web
```

**4. Deploy the application**

```bash
firebase deploy
```

After successful deployment, open the live application:

**[https://neutrifit-e4cec.web.app/](https://neutrifit-e4cec.web.app/)**

### Firebase Project Console

Access the Firebase project dashboard here:

[Open NeutriFIT Firebase Console](https://console.firebase.google.com/project/neutrifit-e4cec/overview)

**Note:** Firebase Console access requires appropriate Google account permissions. Never upload private credentials, service-account keys, or secrets to a public repository.
